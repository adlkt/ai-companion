# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature on the repository's **Security** tab. Do not disclose a suspected vulnerability in a public Issue.

Include the affected version, browser and operating-system versions, reproduction steps, expected and actual behavior, and the potential impact. Do not include real cookies, access tokens, passwords, private conversations, or other sensitive user data.

If private vulnerability reporting is not available yet, open a public Issue containing only a request for a private contact channel and no vulnerability details.

## Scope

AI Companion does not bypass third-party CSP, `X-Frame-Options`, authentication, cookies, or other browser security controls. Behavior caused solely by a third-party website changing its framing or authentication policy may be a compatibility issue rather than a vulnerability in this project.
